# 客户咨询应答话术

> 高频客户问题的标准应答。**先理解客户情绪，再给专业回答**。所有话术可结合实际微调。

## 一、咨询类

**Q1：你们公司转让怎么收费？**
"收费取决于标的公司的情况：公司是否干净、有没有负债诉讼、要不要办资质过户。一般按标的复杂程度分档报价，前期评估不收费，您把公司基本资料发我，我给您出个明确报价。"

**Q2：转让一家公司大概要多久？**
"纯股权转让、资料齐全的情况下，税务加工商一般 2-3 周。如果公司有负债、诉讼或者股东在异地，时间会长一些，具体我可以根据您的公司情况给您排个时间表。"

**Q3：我的公司不想干了，能转让吗？**
"大部分情况可以。先确认两件事：公司有没有欠税、有没有未结的债务诉讼。这两块干净的话，流程很快；有问题我们也能设计方案处理。方便的话把营业执照发我，我先帮您免费查一下。"

## 二、疑虑类

**Q4：转让之后，以前的事还找我吗？**
"股权转让后，公司债务原则上由公司承担，但有两类情况需要特别注意：一是转让前公司欠的税和债，如果没在协议里处理干净，可能被追；二是认缴没实缴的出资义务。这些我们都会在协议里帮您约定清楚，把责任切干净。"

**Q5：买公司安全吗？会不会买到有问题的壳？**
"这正是我们尽调要解决的。我们会查工商、税务、法院、征信四个维度，出具尽调报告，有问题先处理再交易。合同里也会写明卖方的陈述保证和违约责任，出了事有救济途径。"

**Q6：价格怎么定的？凭什么这个价？**
"参考三个数：公司净资产（审计）、资质价值（高新/ICP等）、风险折价（负债、诉讼）。三方一起算出来，我们不会拍脑袋报价，会跟您逐项拆开讲清楚。"

## 三、异议类

**Q7：我自己去办不就行了？为什么找你们？**
"当然可以自己办，但有两个成本：一是时间，流程环环相扣，一次驳回就多一两周；二是风险，材料签错、税没规划好，可能留下后患。我们的价值是省时间、防踩坑，专业的事交给专业的人。"

**Q8：价格能再低点吗？**
"报价是透明的，分项列明。如果您觉得贵，可以缩减服务范围——比如只做尽调+协议，工商税务您自己跑，这样费用能降一半。您看怎么合适？"

## 四、转介绍

**Q9：我朋友也有公司想转，有介绍费吗？**
"有。成交后按合同金额的 X% 给您介绍费，这是我们的长期合作机制，欢迎多介绍。"

## 使用原则

1. 话术是骨架，回答要带入客户的实际情况
2. 不确定的政策点，先查知识库再回答，不现场编
3. 客户问价格 → 永远先了解标的，再报价，不先报数
4. 拿不准的业务场景 → "这个情况我需要跟您确认几个细节"（绝不硬答）
