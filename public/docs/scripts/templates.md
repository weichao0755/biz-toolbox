# 报价与合同模板

> 标准报价单结构与股权转让协议要点清单。正式文件用平台工具生成/线下签署。

## 一、报价单结构

```text
【服务报价单】
客户名称：________    标的公司：________    日期：________

一、服务范围
  1. 尽职调查（工商/税务/司法/征信四维查询 + 报告）
  2. 交易方案设计（含税务筹划建议）
  3. 协议起草与审阅
  4. 税务申报代办
  5. 工商变更代办
  6. 交割与交接指导

二、费用明细
  基础服务费：¥________（按标的复杂程度分档）
  加急服务费：¥________（如需）
  代垫费用：  ¥________（公证、工本费，实报实销）
  合计：      ¥________

三、付款方式
  签约支付 50%，工商变更受理支付 50%

四、服务周期
  预计 ____ 个工作日（从资料齐全之日起算）

五、说明
  1. 若尽调发现重大风险（诉讼、欠税、冻结等），方案与报价需重新评估
  2. 因客户原因导致延期，周期顺延
  3. 本报价有效期 30 天
```

## 二、股权转让协议要点清单

### 必备条款
- [ ] 转让标的：股权数量、占注册资本比例
- [ ] 转让价格与币种
- [ ] 支付节点（绑定里程碑）
- [ ] 交割先决条件（债务清偿、诉讼处理等）
- [ ] 陈述与保证（转让方：股权无瑕疵、无未披露债务/诉讼/税务问题）
- [ ] 过渡期安排（交割前公司经营行为限制）
- [ ] 违约责任（违约金比例、赔偿范围）
- [ ] 税费承担（各自承担法定税负，明确代办方）
- [ ] 争议解决（仲裁或诉讼 + 管辖地）
- [ ] 通知与送达条款

### 附件清单
- [ ] 股东会决议
- [ ] 放弃优先购买权声明
- [ ] 章程修正案
- [ ] 尽调报告摘要
- [ ] 资产/资质清单

## 三、使用规范

1. **报价先谈范围再谈钱**：先确认客户要"全包"还是"部分服务"
2. **协议必须书面**：口头承诺一律落到协议，客户确认后签字
3. **代垫费用留凭证**：发票、收据全部归档，项目结束对账
4. **版本管理**：协议每个版本标注 V1/V2/日期，最终版以签署件为准
