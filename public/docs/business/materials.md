# 材料清单与注意事项

> 一单标准股权转让业务需要的全部材料。按环节归类，办前对照、办后打勾。

## 一、前期资料（客户提供）

- [ ] 标的公司营业执照（正本扫描件）
- [ ] 公司章程（最新版）
- [ ] 股东名册 / 出资证明
- [ ] 全部股东身份证复印件
- [ ] 近 3 年财务报表（或至少资产负债表、利润表）
- [ ] 银行对账单（近 6 个月）
- [ ] 社保公积金缴纳证明
- [ ] 知识产权证书（如有）
- [ ] 已签合同清单（尤其是长周期合同）

## 二、尽调资料（我方出具）

- [ ] 工商内档（登记机关调取）
- [ ] 涉税信息查询（纳税状态、有无欠税、是否非正常户）
- [ ] 司法查询报告（被执行人、失信、裁判文书）
- [ ] 信用报告（中国人民银行企业征信）
- [ ] 尽调结论书（风险清单 + 建议）

## 三、签约文件（双方签署）

- [ ] 股权转让协议（一式多份）
- [ ] 股东会决议（同意转让）
- [ ] 其他股东放弃优先购买权声明
- [ ] 章程修正案（或新章程）
- [ ] 转让款支付凭证（如约）

## 四、税务办理材料

- [ ] 股权转让协议
- [ ] 双方身份证明
- [ ] 股权原值证明（出资凭证、完税记录）
- [ ] 财务报表 / 净资产证明
- [ ] 完税申报表（税务机关现场/网厅办理）

## 五、工商变更材料

- [ ] 公司登记（备案）申请书
- [ ] 股权转让协议原件
- [ ] 完税证明 / 税务申报记录
- [ ] 股东会决议
- [ ] 章程修正案
- [ ] 全体股东身份证明
- [ ] 营业执照正副本原件
- [ ] 指定代表/委托代理人证明

## 六、注意事项（高频踩坑点）

1. **原件 vs 复印件**：工商窗口普遍要原件核验，提前确认当地要求
2. **签字规范**：股东签字必须本人签，代签易被驳回或产生争议
3. **实缴证据**：认缴未实缴的股权，务必让转让方提供出资证明，避免"空转"
4. **税务先行**：部分城市必须税务办结后才受理工商，提前排期
5. **材料一致性**：协议、决议、章程中的转让价格、股比必须完全一致
6. **电子化**：多数城市已支持全程网办，材料拍照上传即可，但涉税材料仍需线下

## 七、归档要求

- 命名：`YYYYMM-客户简称-标的公司-单号`
- 文件：全部扫描 PDF 存档 + 原件清单登记
- 保密：标的公司财务资料仅项目组可见，项目结束归档加密
