# 公司转让全流程

> 从接触客户到项目归档的完整操作手册。新人按此流程执行，资深顾问按此流程复核。

## 一、前期：接单与评估

1. **收集标的信息**：公司全称、成立时间、注册地、注册资本（实缴/认缴）、经营范围、有无经营
2. **判断转让类型**：
   - 股权转让（最常用）：股东把股权转给受让方，公司主体不变
   - 法定代表人变更：只换人，股权不变（常配合股权转让一起做）
   - 资产转让：只卖资产/资质，原公司清算注销
3. **初步风险筛查**：企查查/天眼查拉取：工商状态（正常/吊销/注销）、司法风险、经营异常、股权冻结

## 二、尽调：核心风险排查（重点环节）

| 排查项 | 查询渠道 | 风险等级 |
| --- | --- | --- |
| 工商档案 | 国家企业信用信息公示系统 | 高 |
| 税务状态（欠税/非正常户） | 主管税务机关 | 极高 |
| 债务与诉讼 | 中国执行信息公开网、裁判文书网 | 极高 |
| 社保/公积金欠缴 | 社保局、公积金中心 | 中 |
| 知识产权（商标/专利/软著） | 商标局、专利局 | 中 |
| 银行账户/贷款 | 开户行征信 | 高 |

> **铁律**：尽调不完成，不进谈判环节。尽调结果直接决定方案和价格。

## 三、方案与谈判

- 干净公司（无负债无诉讼）→ 直接股权转让，流程 2-3 周
- 有负债/有纠纷 → 先谈债务处理（卖方清偿 / 买方承接折价），再转让
- 有特殊资质（高新、ICP、建筑资质）→ 资质溢价，注意资质随主体转移的条件

## 四、签约

- 协议必备条款：标的股权/资产、价格与支付节点、交割条件、陈述与保证、过渡期安排、违约责任、争议解决
- 同时签署：股东会决议、放弃优先购买权声明（其他股东）、章程修正案

## 五、税务（先税后工商）

1. 印花税：转让金额 × 0.05%（产权转移书据）
2. 个人所得税：自然人股东转让，差额 × 20%（可扣减原值及合理费用）
3. 企业所得税：法人股东转让，并入当期所得
4. 取得完税证明/申报记录 → 才可进工商环节

## 六、工商变更

- 股权变更：提交《股权转让协议》、完税证明、股东会决议、章程修正案
- 法定代表人变更：同时办理（部分城市要求先办股权再办法人）
- 领取新执照后：税务登记信息同步、银行账户法人变更、印章更换（如约定）

## 七、交接归档

- 移交：营业执照、公章财务章、账册凭证、资质证书、银行U盾、合同档案
- 平台归档：按"一单一档"命名 `YYYYMM-客户简称-标的公司`，上传关键文件

## 常见驳回原因

- 未提供完税证明 / 税务未办结
- 股东会决议签字缺失或无效
- 章程修正案与协议内容不一致
- 认缴资本未实缴引发的争议未在协议中约定处理
