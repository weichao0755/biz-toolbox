# 进阶学习路径

> 从"能干活"到"能挑大梁"的成长路线。新人到资深，按这个路径走。

## 阶段一：执行者（0-3 个月）

**目标**：独立完成简单项目，不出错。

- [ ] 掌握全流程 9 环节（已具备）
- [ ] 独立完成尽调信息收集（对照清单逐项核验）
- [ ] 独立准备全套工商材料，一次通过
- [ ] 独立完成税务申报代办
- **考核**：连续 3 单无材料驳回、无流程返工

## 阶段二：方案者（3-12 个月）

**目标**：能针对复杂标的独立设计方案。

- [ ] 掌握债务处理、诉讼处理、资质过户三类复杂场景方案
- [ ] 能独立完成价格谈判（有成交记录）
- [ ] 能看懂财务报表：资产负债表、利润表、现金流量表
- [ ] 熟悉税务筹划基本方法（平价转让、先分红再转让等，注意合规）
- **考核**：独立承接一单"有负债"项目并成交

## 阶段三：顾问（1-3 年）

**目标**：成为客户信任的业务顾问，能带新人。

- [ ] 能跨行业（科技/贸易/建筑/医疗）评估标的
- [ ] 掌握并购视角：交易架构（股权/资产/吸收合并）的取舍
- [ ] 能带 1-2 名新人，输出带教文档
- [ ] 形成个人方法论：至少 10 篇案例复盘入库
- **考核**：独立承接并交付一单"高复杂"项目（诉讼+负债+资质多因素叠加）

## 推荐学习资源

| 主题 | 资源 |
| --- | --- |
| 公司法 | 《公司法》2023 修订版全文 + 司法解释 |
| 税务 | 国家税务总局 2014 年第 67 号公告（股权转让个税） |
| 尽调 | 平台案例库全部案例 + 尽调报告模板 |
| 谈判 | 《谈判力》(Getting to Yes) |
| 财务 | 平台内财务速成笔记 / 会计基础课程 |

## 每月固定动作

1. **月初**：复查法规更新（公司法、税法、市场监管新规）
2. **月中**：至少读 2 篇案例库文档 + 写 1 篇自己的复盘
3. **月末**：和带教人/资深顾问做一次案例研讨（1 小时）

## 关于"资深"

> 资深的标志不是年限，是**独立判断能力**：客户问一个陌生问题，你能判断"这个问题知识库里有没有、该不该问人、能不能当场答"。走到这一步，你就是团队的中坚。
