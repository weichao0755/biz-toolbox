# 失败复盘：资料不全导致延期

> 一单本应 3 周完成的业务拖了 2 个月，最后客户流失。复盘是为了不再犯。

## 背景

- 标的：某贸易公司，无负债、无诉讼，看似"干净"的简单股权转让
- 卡点：**转让方股东之一在海外，无法线下签字**；且公司成立时注册资本为认缴，无实缴记录

## 时间线

| 时间 | 发生的事 | 问题 |
| --- | --- | --- |
| 第 1 周 | 尽调完成，一切正常，开始准备签约 | 未提前确认股东签字条件 |
| 第 2 周 | 发现 A 股东在海外，签字需公证/认证 | 措手不及，流程停滞 |
| 第 3 周 | 尝试远程视频签字，当地工商不认 | 政策没吃透 |
| 第 5 周 | 补做海外公证 + 领事认证（往返快递 2 周） | 时间成本巨大 |
| 第 6 周 | 税务环节发现认缴转实缴无记录，需补充出资流水证明 | 材料清单漏项 |
| 第 8 周 | 客户失去耐心，转而咨询别家 | 项目流失 |

## 根因分析

1. **签约前没有做"签字能力"评估**——股东能否本人到场/能否公证，应该在尽调阶段就问清
2. **材料清单按模板走，没针对个案补充**——认缴转实缴、海外股东这两类特殊项没提前预案
3. **政策确认滞后**——远程签署是否被认可，应在第 1 周就电话咨询当地市监局

## 改进措施（已落地）

- [x] 尽调清单新增"股东签字能力"检查项（所在地、能否到场、是否需公证）
- [x] 材料清单增加"实缴证明"专项，认缴公司强制要求提供出资流水
- [x] 建立"疑难场景提前咨询"机制：海外股东、司法冻结、非正常户等 8 类场景，签约前必须电话确认当地政策
- [x] 项目启动会新增一项：**预估延期风险 Top 3** 并写进项目档案

## 给新人的话

> 这单不是输在专业，是输在"想当然"。公司看着干净 ≠ 流程顺利。**每个股东、每笔出资、每份材料，都假设它有问题，然后去验证。**
