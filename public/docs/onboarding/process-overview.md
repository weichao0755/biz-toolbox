# 业务流程总览

> 公司转让业务的 9 个标准环节。新人先记住这张图，再逐个环节深入。

## 一单业务的标准路径

```text
线索获取 → 需求评估 → 尽职调查 → 方案设计 → 价格谈判
→ 协议签署 → 税务办理 → 工商变更 → 交接归档
```

## 环节说明

### 1. 线索获取
- 渠道：老客户转介绍、中介平台、园区/代理记账合作方、自主获客
- 关键动作：记录客户来源、标的公司基本信息（行业、成立年限、财务规模）

### 2. 需求评估
- 判断买卖双方的真实诉求：买方要资质还是要壳？卖方为什么转让？
- 输出：初步可行性判断 + 服务报价

### 3. 尽职调查
- 查工商档案、税务状态、负债、诉讼、社保公积金、知识产权
- 输出：尽调报告，标注风险点（这决定方案怎么设计）

### 4. 方案设计
- 根据尽调结果选择交易路径：直接股权转让 / 资产剥离 / 先清算再收购
- 输出：交易方案书（含税务筹划建议）

### 5. 价格谈判
- 定价依据：净资产 + 资质溢价 - 风险折价
- 输出：双方认可的交易价格与付款节点

### 6. 协议签署
- 股权转让协议 / 资产转让协议，明确交割条件、陈述与保证、违约责任
- 输出：签署完成的协议文本

### 7. 税务办理
- 印花税、个人所得税（股权转让 20%）、企业所得税申报
- **先税后工商**：完税证明是工商变更的前置条件

### 8. 工商变更
- 股权变更、法定代表人变更、章程修正、股东名册更新
- 输出：新营业执照、变更登记通知书

### 9. 交接归档
- 印章、账册、银行账户、资质证书移交
- 平台档案目录归档，项目关闭

## 新人注意

- 环节 3（尽调）是专业性分水岭，前期一定跟着资深顾问做
- 环节 7、8 的顺序不能乱：**先税务，后工商**，否则变更会被驳回
- 每单结束写复盘：哪些环节耗时最长？客户在哪个环节犹豫？沉淀进案例库
