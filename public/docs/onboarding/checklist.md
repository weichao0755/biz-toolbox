# 新人必学清单

> 把下面每一项都打勾，你就具备独立跟进简单项目的基础能力。

## 必备知识（读）

- [ ] 业务流程总览（9 个环节）
- [ ] 公司转让全流程细节
- [ ] 核心政策法规：公司法、税法要点
- [ ] 常见公司类型差异（有限/股份/个人独资/合伙）
- [ ] 材料清单与注意事项

## 必备技能（练）

- [ ] 会用平台内所有业务工具（高新申请方案生成器等）
- [ ] 能独立回答 10 条高频客户问题（背熟话术库）
- [ ] 能独立填写一份报价单
- [ ] 能按材料清单核验一单材料是否齐全
- [ ] 能讲清"先税后工商"的原因

## 必备工具（用）

- [ ] 业务工具箱：高新申请方案生成器
- [ ] 知识库搜索：30 秒内找到一篇文档
- [ ] 档案管理规范：项目资料归档位置与命名

## 上岗标准

1. 清单全部勾选；
2. 通过带教人口头考核（模拟客户咨询，能独立给出准确回答）；
3. 独立完成一单"纯股权转让、无负债、无诉讼"的简单案例（模拟）；
4. 在案例库提交一篇自己的复盘笔记。
