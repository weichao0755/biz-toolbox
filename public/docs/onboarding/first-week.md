# 入职第一周指南

> 目标：第一周结束，你能独立讲清"公司转让是做什么的"，并能跟着带教人走完一单简单业务。

## Day 1：建立全局认知

- [ ] 读完《业务流程总览》，记住 9 个环节的名字和顺序
- [ ] 打开平台「工具」页，试用一次高新申请方案生成器
- [ ] 向带教人复述：公司转让 = 帮卖方把公司（股权/资产/资质）过户给买方

## Day 2：吃透核心流程

- [ ] 精读《公司转让全流程》，对照流程图过一遍
- [ ] 整理出"先税后工商"的完整顺序，讲给带教人听
- [ ] 记住三类常见转让：股权转让、法定代表人+股权、资产剥离式转让

## Day 3：政策与风险

- [ ] 读《核心政策法规速览》，圈出公司法、个税/企业所得税相关条款
- [ ] 读《常见公司类型与转让要点》，能说出有限公司和股份公司的核心差异
- [ ] 学会识别"高危标的"：有诉讼、有负债、税务异常、失信被执行人的公司

## Day 4：材料与实操

- [ ] 对照《材料清单与注意事项》核验一单虚拟案例的材料
- [ ] 背熟《客户咨询应答话术》前 10 条高频问答
- [ ] 在平台上完成一次知识库搜索练习：30 秒内找到"股权转让需要哪些材料"

## Day 5：模拟上岗

- [ ] 完成《新人必学清单》全部勾选项
- [ ] 通过带教人口头考核（模拟客户咨询场景）
- [ ] 输出一份自己的《一周学习总结》，存进知识库

## 常见问题

**问：第一周就要背很多东西吗？**
不用死记硬背。重点是"知道去哪查"：知识库搜得到、话术库翻得到、带教人问得到。理解 > 背诵。

**问：遇到拿不准的业务怎么办？**
绝不擅自定义。先查知识库 → 再问带教人 → 拿不准就上报，不向客户承诺任何未确认的事项。
